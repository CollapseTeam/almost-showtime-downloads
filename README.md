# Almost Showtime per Windows

Scarica il **launcher 2.3.1** dalla [pagina dell'ultima versione](https://github.com/CollapseTeam/almost-showtime-downloads/releases/latest).

1. Scarica lo ZIP del launcher con la versione piu recente.
2. Estrai tutto lo ZIP e apri AlmostShowtimeLauncher.exe.
3. Chiudi eventuali copie del gioco aperte e premi **Installa**. Alla prima installazione scegli una cartella vuota.

Se hai cancellato la cartella del gioco, il launcher 2.3.1 consente la reinstallazione nella posizione scelta in precedenza senza cancellare i salvataggi. Le versioni precedenti possono mostrare un errore relativo a .asrelease.json: scarica il nuovo launcher.

Non serve un account GitHub. Il launcher controlla gli aggiornamenti all'apertura. Per avviare occorrono una verifica online riuscita e il gioco aggiornato: quando esiste una nuova versione, usa **Aggiorna**. Il launcher non si aggiorna da solo; scarica il nuovo ZIP quando richiesto.

Sono disponibili **Installa**, **Aggiorna**, **Avvia gioco**, **Verifica file**, **Apri cartella** e **Copia percorso**.

Per giocare insieme usate tutti la stessa versione del gioco. Questo repository contiene soltanto pacchetti di distribuzione, non i sorgenti Unity.

I download sono pubblici: puoi condividere questa pagina con gli amici.
