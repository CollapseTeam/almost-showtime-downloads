# Almost Showtime per Windows

Scarica il launcher dalla [pagina dell'ultima versione](https://github.com/CollapseTeam/almost-showtime-downloads/releases/latest).

1. Scarica il file `AlmostShowtimeLauncher-2.2.0-Windows-x64.zip`.
2. Estrai tutto lo ZIP e apri `AlmostShowtimeLauncher.exe`.
3. Premi **Installa** e scegli una cartella vuota per il gioco.

Non serve un account GitHub. Il launcher controlla gli aggiornamenti all'apertura; premi **Aggiorna** per installarli. Il gioco gia installato si avvia anche offline.

Sono disponibili **Avvia gioco**, **Installa**, **Aggiorna**, **Verifica file**, **Apri cartella** e **Copia percorso**.

Per giocare insieme usate tutti la stessa versione. Questo repository contiene soltanto pacchetti di distribuzione, non i sorgenti del progetto Unity.

I download sono pubblici: puoi condividere questa pagina con gli amici.
